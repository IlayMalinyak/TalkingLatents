\section{Results}\label{sec:results}
% We ask whether a learned representation is a sufficient interface for a language model to
% analyse data, beyond describing it. Two reference points bracket every result. Probes trained on
% the same features show what the representation contains. Frontier models given the raw
% observations show what is reachable without it. The progression from single objects to pairs
% to groups is tested on stars; galaxies test description and the effect of the adaptation
% method on a single-object reasoning task. All narrators use AstroSage-8B
% \citep{haan2025_astrosage}; with the same training, Llama-3.1-8B gives the same results to
% within $0.05$ on every single-object and pair metric (\Cref{app:basemodel}).

\subsection{Describing single objects}\label{sec:description}
The first task is to describe a single object. We compare each narrator with linear probes
trained on the tokens it reads: ridge regression for numerical properties and logistic
regression for classes, fit on the training objects and evaluated on the test objects. We
report $R^2$ for numerical properties and balanced accuracy for classes. A narrator does not
state every property for every object, so we score it only on the objects for which it states
the property and evaluate the probe on the same objects. A narrator that matches the probe
conveys the information that the tokens encode linearly. We also report a non-linear probe, an
MLP with one hidden layer of $512$ units. \Cref{tab:single} gives the results.

\textbf{Stars.} The LoRA narrators match or exceed the linear probe on every property
(\Cref{tab:single}). The fully fine-tuned narrator does so on all properties except
temperature and age. Part of this advantage is recall: the narrator often states the exact
catalog value of a star described in its training text (\Cref{sec:memorization}). Age is weak
for every readout, including the probe ($R^2=0.55$ on all test stars), so the limit lies in the tokens rather
than in the narrator. Opus 5.5, reading the raw observations zero-shot, is well below the probe
on every property ($R^2$ between $-0.26$ and $0.57$; balanced accuracy $0.67$ on the
evolutionary state).

\textbf{Galaxies.} No test galaxy appears in the training text, so recall is not possible. On
all five numerical properties, the narrator's $R^2$ exceeds that of the probe on the same
galaxies. On classes, it matches the probe for morphology, quenching state and SFH trend, and
falls below it for disturbance ($0.67$ vs.\ $0.82$).
Its main limitation is coverage: it states the stellar mass for only $8\%$ of galaxies and the
redshift for $18\%$, although the probe recovers both well.

Single-object description therefore reaches the level of a linear probe on the same tokens,
including on galaxies, where recall is excluded. The harder question is whether the same
interface supports reasoning across several objects.

\subsection{Comparing two objects}\label{sec:pairs}
The second task is to compare two objects. The narrator reads the tokens of both objects and
describes how they differ. We score every comparison it states against the catalog and report
relational accuracy, the fraction of stated comparisons that are correct. For stars a
comparison is an order (e.g.\ ``A is hotter than B''); a probe compares two stars by predicting
the property for each and taking the sign of the difference. For galaxies it is a relation
class (e.g.\ same or different morphology); a probe assigns the class from its predicted labels
for both galaxies. As for single objects, we evaluate the probes on the comparisons each narrator
states (\Cref{tab:pair}).

The narrators compare stars more accurately than the probes. The LoRA narrator with the tool
exceeds both probes on every property; the other two narrators fall below the non-linear probe
only on age, and the fully fine-tuned narrator also on its $49$ metallicity comparisons. The
ordering of the narrators is the same as for single objects: full fine-tuning $\le$ LoRA $<$
LoRA with the tool on every property. As
for single objects, part of this advantage may be recall of the training text
(\Cref{sec:memorization}). Opus 5.5, reading the raw observations zero-shot, is below both probes
on every property except radius.

On galaxies the result is reversed. The fully fine-tuned narrator, the only one run on galaxy
pairs, is below both probes on every relation, by $0.02$ to $0.09$ against the linear probe and
$0.06$ to $0.16$ against the non-linear probe. Unlike
the stellar narrators, it cannot draw on training descriptions of the test objects
(\Cref{sec:data}).

\subsection{Reasoning across objects and modalities}\label{sec:population}
The third task requires reasoning: the answer is not stated for any single object or
modality and must be inferred by combining them. We test two forms. In the stellar
\emph{population task}, the narrator reads a group of $4$ to $32$ stars and must name the member
that does not belong and the property in which it differs, which requires comparing every
member with the rest. We score whether the text names the odd star \emph{and} its property
(judge; \Cref{app:eval}). In the galaxy \emph{cross modal task}, the narrator must state whether
a galaxy's shape agrees with its star-formation history, which requires relating its two
modalities. \Cref{tab:group} gives the results for every model we tested.

\textbf{Results.} On the population task, the training method determines the outcome. The fully
fine-tuned narrator names the odd star and its property in $33\%$ of the test groups; the LoRA
narrator does so in $63\%$, and $66\%$ with the tool. Test stars also appear in training
(\Cref{sec:data}), so a narrator could recall which star was odd instead of finding it. We
therefore also built $1{,}000$ \emph{never-odd} groups from the test fold, whose odd star was
never the odd member of a training group ($2.3\%$ of candidate groups pass this filter). The
ordering is the same on these groups ($0.28$, $0.62$ and $0.75$). The filter changes the mix of
odd stars: binarity makes the star odd in $54\%$ of these groups against $26\%$ of the test
groups, and metallicity in $1\%$. We therefore compare models within each set, not across sets.

The tool adds $0.03$ on the test groups ($0.633 \to 0.662$, $p=0.07$) and $0.13$ on the
never-odd groups ($0.615 \to 0.748$, $p=5\times10^{-15}$). Part of this gain lies in groups
whose odd star is a binary ($0.48 \to 0.64$), and binarity is one of the tool's labels. The
gain remains without them ($0.78 \to 0.88$, $n=458$, $p=6\times10^{-6}$). The tool is not an
answer on its own: ranking the members by its surprise score puts the odd star first in $29\%$
of groups, and when its top choice is wrong, the tool narrator follows it no more often than
the fully fine-tuned narrator does ($7\%$ against $8\%$). The narrator does read the token:
scrambling it across the group or zeroing it drops the score below that of the narrator trained
without the tool (\Cref{tab:ablate}).

Frontier models score below every narrator. We give Claude Opus 5.5 and Claude Fable 5.1 each
star's raw observations: plots of its Kepler and TESS light curves and its LAMOST and APOGEE
spectra, and its Gaia measurements as text, with no derived stellar parameters
(\Cref{app:frontier}). Zero-shot, both score $0.20$ on a subset of $177$ test groups, on which
the latent narrators score $0.33$, $0.63$ and $0.64$ ($p<10^{-13}$ against the LoRA narrators,
$p=0.005$ against full fine-tuning). Opus scores $0.20$ on the never-odd groups as well. Both
frontier models make about twice as many contradictions per group as the narrators
(\Cref{tab:frontier}), and giving the observations as tables instead of plots does not help
(\Cref{app:frontier}). An agent that can run code on the unbinned observations, with star
identifiers hidden and no network access, scores $0.18$ ($p=0.57$ against zero-shot). The
frontier models were not trained on this task; the comparison measures what a general-purpose
model does without training. Models that read the catalog values as a table, also without
training on the task, score below the LoRA narrator as well (\Cref{app:text}).

On the agreement task, all narrators reach
$0.98$--$0.99$ on star-forming galaxies. On quiescent galaxies the fully fine-tuned narrator
falls to $0.88$, against $0.97$ for LoRA and $0.98$ with the tool; most of its errors state
that a quiescent galaxy still forms stars (\Cref{app:2x2}). The galaxy tool adds nothing, as
expected, since it is computed from the same embeddings the narrator reads. The rest of this subsection
examines the failure of full fine-tuning and tests whether the features contain the answer.

\textbf{The failure is not due to the optimizer settings.} We note that the fully fine-tuned and LoRA narrators were trained with different optimizers.
 A LoRA narrator trained with the optimizer settings
of the fully fine-tuned one still scores well above it ($0.51$ against $0.33$ on the test
groups, $0.59$ against $0.28$ on the never-odd groups, $p<10^{-24}$; \Cref{sec:tokenortraining}).
We read this as a condition for the approach to work, not as a claim that LoRA is better in
general; it is consistent with the finding that LoRA preserves more of the base model's
abilities than full fine-tuning \citep{Biderman2024_lora}.

\textbf{The failure grows with the number of stars.} On single objects and pairs the gap between the two
methods exists but is smaller (\Cref{tab:single,tab:pair}). To test if the population size drives the difference,
we vary only the number of stars, keeping the question fixed
(\Cref{fig:groupsize}). We show the $1{,}000$ never-odd groups. With full fine-tuning, the score
falls from $0.38$ with $4$ stars to $0.04$ with $32$ (Spearman $\rho=-0.27$, $p=10^{-18}$). The
LoRA narrator stays between $0.57$ and $0.69$ and does not decline ($\rho=+0.07$, $p=0.04$). With
the optimizer settings of the fully fine-tuned narrator, the LoRA narrator declines from $0.62$ to
$0.34$ ($\rho=-0.10$, $p=10^{-3}$). The same effect is seen on all test groups
(\Cref{app:groupsize}). Since every star adds the same number of tokens, a larger group
is also a longer input, and our data cannot separate the two.

\textbf{The features contain the answer.} To test whether the failure lies in the tokens or in
the readout, we rank the members of each group with a linear probe on the same features
(\Cref{app:probe}). For each odd star on a continuous property (temperature, surface gravity,
metallicity), we ask whether a star with the odd label is the most extreme member of its group
by the probe's prediction. Binarity and cluster membership cannot be ranked this way. We score
the narrators on the same odd stars with the same rule: credit when the text calls out a star
with the odd label. \Cref{tab:probegroup} shows the result. Ranked by the probe, the features
place a qualifying star first as often as the true catalog values do ($0.72$ against $0.73$), so
the information the task needs is in the features. The fully fine-tuned narrator reaches about
half of this. The LoRA narrator is below the probe on the test groups ($0.66$ against $0.72$,
$p=5\times10^{-4}$) and above it on the never-odd groups ($0.80$ against $0.73$, $p=0.01$). On the test groups,
every narrator is far below the probe on dwarfs and giants and above it on metallicity
(\Cref{app:probe}). The two readouts differ in kind: the probe ranks by distance
from the group median, while the labels are thresholds. We therefore do not claim that the
narrator reaches the limit of the features, only that the features hold the answer and that
the fully fine-tuned narrator fails to read it.

\subsection{Memorization controls}\label{sec:memorization}
Because the stellar data are split per description (\Cref{sec:data}), every test star also
appears in training, and the narrator can memorize the values written about it. It does: it
gives the exact temperature in $35\%$ of its statements, against $0.5\%$ for a probe on the same
tokens, and almost every exact value appears in a training description of the same star. Its
mean error, however, is similar whether or not a training description of the star states the
value (\Cref{app:memo}). Whether a model memorizes the result of reasoning is a different
question, with wider implications: modern LLMs have seen data on many of the objects they are
asked about. We test it on the never-odd groups (\Cref{sec:population}). There, the narrators
keep their order on every measure, and LoRA's gain over full fine-tuning is $0.34$, against $0.30$
on the test groups (\Cref{tab:group}; by named star and property in \Cref{tab:adversarial}). The narrator thus recalls values, but finds the odd
star from the input.
