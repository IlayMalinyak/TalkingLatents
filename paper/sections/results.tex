\section{Results}\label{sec:results}
We ask whether a learned representation is a sufficient interface for a language model to
analyse data, beyond describing it. Two reference points bracket every result. Probes trained on
the same features show what the representation contains. Frontier models given the raw
observations show what is reachable without it. The progression from single objects to pairs
to groups is tested on stars; galaxies test description and the effect of the adaptation
method on a single-object reasoning task. All narrators use AstroSage-8B
\citep{haan2025_astrosage}; with the same training, Llama-3.1-8B gives the same results to
within $0.05$ on every single-object and pair metric (\Cref{app:basemodel}).

\subsection{Describing single objects}\label{sec:description}
We compare the narrator with linear probes on the tokens it reads (ridge regression for
numbers, logistic regression for classes), trained on the training objects and tested on the
test objects. We use standard metrics: $R^2$ for numbers, balanced accuracy for classes, and
the fraction of stated values within $10\%$ of the catalog value (\Cref{app:eval}). The
narrator writes free text and does not state every property for every object, so we score it
on the objects where it states the property and give the probe's score on the same objects
next to it. \Cref{tab:single} shows the result.

\textbf{Galaxies.} No test galaxy appears in the training text, so this is the clean
comparison. Where the narrator states a number, its $R^2$ is at or above that of the linear
probe on the same galaxies, and about equal to that of a non-linear probe
(\Cref{app:probevsnarrator}). On classes it equals the probe for morphology, quenching and the
star-formation trend, and is below it for recent activity and disturbance. The narrator
states several numbers for only a minority of galaxies (stellar mass for $8\%$, redshift for
$18\%$), although the probes read them well.

\textbf{Stars.} The narrators are at or above the probe on most numbers and classes, and the
LoRA narrators are above the fully fine-tuned one. Part of this advantage is recall: the
narrator often states the exact catalog value of a star it read about in training
(\Cref{sec:memorization}). Age is weak for every readout, which points to the tokens rather
than the narrator. Opus 5.5, reading the raw observations zero-shot, is well below the probe
on every property ($R^2$ between $-0.26$ and $0.57$, and $0.67$ balanced accuracy on the
evolutionary state). Pairs show the same ordering of the narrators (\Cref{app:regime}).

The narrator therefore describes single objects about as well as a probe on the same tokens,
and on galaxies, where recall is not possible, this holds as well. Description is the easy
case. The question is whether the same interface supports analysis across several objects.

\subsection{Finding the odd star: reasoning over a group depends on adaptation}\label{sec:population}
In the stellar group task the narrator reads a group of $4$ to $32$ stars and must name the
member that does not belong and the property in which it differs. A group can be answered only
by comparing every member with the rest. We score whether the text names the odd star
\emph{and} its property (judge; \Cref{app:eval}). The galaxy task asks whether a galaxy's
shape agrees with its star-formation history. It concerns one object, but it requires
relating two of its modalities. \Cref{tab:group} collects every model we tested on these
tasks. This subsection discusses the latent narrators; \Cref{sec:interface} discusses the
other rows, and \Cref{sec:ltu} the last two.

\textbf{Full fine-tuning fails on groups; LoRA does not.} The fully fine-tuned narrator reads
the data tokens and names the odd star and its property in only a third of the test groups.
The same model trained with LoRA on a frozen base, on the same text and the same tokens, does
so in $63\%$ of them, and the gap is as large on the groups whose answer never appeared in
training ($0.28$ against $0.62$). On galaxies the same comparison favours LoRA on quiescent
galaxies ($0.97$ against $0.88$; \Cref{app:2x2}), where most errors of the fully fine-tuned
narrator state that a quiescent galaxy still forms stars. We did not tune either recipe, and
the two used different optimizer settings. A LoRA narrator trained with the optimizer settings
of the fully fine-tuned one still scores well above it ($0.51$ against $0.33$ on the test
groups, $0.59$ against $0.28$ on the never-odd groups, $p<10^{-24}$; \Cref{sec:tokenortraining}).
We read this as a condition for the approach to work, not as a claim that LoRA is better in
general; it is consistent with the finding that LoRA preserves more of the base model's
abilities than full fine-tuning \citep{Biderman2024_lora}.

\textbf{The failure grows with the number of stars.} On single objects and pairs the gap between the two
methods is small (\Cref{app:regime}), so we vary only the number of stars, keeping the question fixed
(\Cref{fig:groupsize}). With full fine-tuning, the score falls from $0.45$ with $4$ stars to
$0.06$ with $32$ (Spearman $\rho=-0.24$, $p=10^{-16}$). The LoRA narrator stays between $0.53$
and $0.70$ with no significant trend ($\rho=+0.01$, $p=0.7$). With the optimizer settings of
the fully fine-tuned narrator, the LoRA narrator declines only mildly, from $0.51$ to $0.34$
($\rho=-0.06$, $p=0.04$). The same pattern holds on the never-odd groups
(\Cref{fig:groupsize}, right). Since every star adds the same number of tokens, a larger group
is also a longer input, and our data cannot separate the two.

\textbf{The features contain the answer.} To test whether the failure lies in the tokens or in
the readout, we rank the members of each group with a linear probe on the same features
(\Cref{app:probe}). For each odd star on a continuous property (temperature, surface gravity,
metallicity), we ask whether a star with the odd label is the most extreme member of its group
by the probe's prediction. Binarity and cluster membership cannot be ranked this way. We score
the narrators on the same odd stars with the same rule: credit when the text calls out a star
with the odd label. \Cref{tab:probegroup} shows the result. Ranked by the probe, the features
place a qualifying star first as often as the true catalog values do ($0.72$ against $0.73$), so
the information the task needs is in the features. The fully fine-tuned narrator reaches about
half of this. The LoRA narrator is below the probe on the test groups ($0.66$ against $0.72$,
$p=5\times10^{-4}$) and above it on the never-odd groups ($0.80$ against $0.73$, $p=0.01$). On the test groups,
every narrator is far below the probe on dwarfs and giants and above it on metallicity
(\Cref{app:probe}). The two readouts differ in kind: the probe ranks by distance
from the group median, while the labels are thresholds. We therefore do not claim that the
narrator reaches the limit of the features, only that the features hold the answer and that
the fully fine-tuned narrator fails to read it.

\subsection{Is the representation the right interface?}\label{sec:interface}\label{sec:text}
The failure of full fine-tuning raises the question of whether the latent tokens are needed at
all. We compare them with two alternatives: the catalog values as text, and the raw
observations given to a frontier model.

\textbf{The catalog as text.} Each group is shown as a table with one row per star, listing its
catalog values together with the two catalog flags the tool also receives (binarity and
open-cluster membership). The model sees two worked examples and is asked to name the star that
does not belong and its property. Without training on the task, no model that reads the table
reaches the LoRA narrator (\Cref{tab:text}; $p<10^{-14}$). AstroSage-8B scores $0.473$, but by
naming most of the group: naming the odd star among them is then no better than chance. Qwen3.5-27B
is more selective, but often gets the odd star's property wrong, and scores $0.341$, no
different from the fully fine-tuned narrator. Asking either model to reason first does not
help (\Cref{app:text}). These models were not trained on the task. To compare the two
interfaces under the same training, we trained the LoRA narrator on the same text with each
star's catalog row in place of its data tokens: \TODO{run A (text-only LoRA) results, by group
size and kind of odd star; if it matches or beats the latent narrator, report it and revise
the claims of this section}.

\textbf{Frontier models on the raw observations.} We give Claude Opus 5.5 and Claude Fable 5.1
each star's raw observations, namely plots of its Kepler and TESS light curves and its LAMOST
and APOGEE spectra, together with its Gaia measurements as text, with no derived stellar
parameters (\Cref{app:frontier}). Zero-shot, without tools, both score $0.20$ on groups, below
every narrator ($p<10^{-13}$ against the LoRA narrators and $p=0.005$ against full
fine-tuning), and they make about twice as many contradictions (\Cref{app:frontier}). On
single stars Opus is well below the probes (\Cref{tab:single}). Replacing the plots by tables
of the same observations does not change this. The narrators were trained on this task, on
descriptions of these stars, so this measures what a general-purpose model does out of the box.
An agent that can run code on the unbinned observations, with star identifiers hidden and no
network access, is the stronger baseline: \TODO{run C (frontier agents with code; raw

\subsection{Memorization controls}\label{sec:memorization}
A narrator trained on templated text, and on the stars it is later tested on (\Cref{sec:data}),
could copy instead of read. It could copy the wording of its training descriptions, the values
written about a particular star, or the answer to a reasoning question. The first two happen to
a limited extent and are measured in \Cref{app:memo}: the training recipe removes copying of
wording, and the stellar narrator states exact catalog values it read about the same star,
which raises its single-star precision but barely changes its average error. The objection
that matters most is the third: a narrator might recall which star was called unusual in
training rather than work it out.

We test this in two ways (\Cref{tab:adversarial}). First, we split the $1{,}203$ test groups
by whether the odd star was ever the odd member of a training group. Almost all were
($1{,}167$), and on the $36$ that were not, the narrators keep their order. Because that set is
small, we also built $1{,}000$ new groups from the test fold whose odd star was never an odd
member in training, which keeps $2.3\%$ of candidate groups. On these, LoRA gains $0.34$ over
full fine-tuning, so that gain is not recall. This set is harder by construction, since stars
that survive the filter are rarely odd, so only differences within it are comparable.

\subsection{Extension: auxiliary information through a latent tool}\label{sec:ltu}
The probes show that the features contain the continuous properties the group task needs. Some
information, however, exists outside the representation, for example whether a star is a known
binary or a member of an open cluster. When auxiliary information exists outside the
representation, a separate model can pass it to the narrator as a latent token. We test this as
a preliminary extension.

\textbf{The tool.} In the stellar case the tool is a flow-matching model trained on the joint
distribution of a star's aligned features and six catalog labels ($T_\mathrm{eff}$, $\log g$,
$[\mathrm{Fe/H}]$, rotation period, binarity and cluster membership), conditioned on the rest of
the group. For each star it returns how surprising the star is under that model and the values
the group would predict for it, eleven numbers in all, which a trained projection maps to that
star's tool token. The labels are inputs of the tool at test time as well as in training, and
narrators without the tool do not receive them. In the galaxy case the tool is a cross-modal
predictor trained to predict one modality from the other. The stellar tool is not an answer on
its own: ranking the members by its surprise score puts the odd star first in $29\%$ of groups.

\textbf{What it adds.} With the training held fixed, the tool adds $0.03$ on the test groups
($0.633 \to 0.662$, $p=0.07$) and $0.13$ on the never-odd groups ($0.615 \to 0.748$,
$p=5\times10^{-15}$; \Cref{tab:group}). Part of this gain lies in groups whose odd star is a
binary, $54\%$ of the never-odd set ($0.48 \to 0.64$), and binarity is one of the tool's labels.
The gain remains without them ($0.78 \to 0.88$, $n=458$, $p=6\times10^{-6}$). When the tool's
own top choice is wrong, the tool narrator follows it no more often than the fully fine-tuned
narrator does ($7\%$ against $8\%$), so it does not copy a verdict from the token. It does read
the token: on the test groups, scrambling the token across the group costs $0.056$ and zeroing
it costs $0.101$ (\Cref{tab:ablate}). On the never-odd groups the costs are larger: scrambling costs $0.197$ ($0.748 \to 0.551$)
and zeroing costs $0.401$ ($\to 0.347$), both below the narrator trained without the tool
($0.615$; \Cref{tab:ablate}).
On galaxies the tool adds nothing, as expected, since it is computed from the same embeddings
the narrator reads (\Cref{app:2x2}).

from the labels alone. We trained a narrator with the same recipe in which each star's extra
