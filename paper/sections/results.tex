\section{Results}\label{sec:results}
\subsection{singles and pair questions}
We first test the single and pair questions, comparing two types of Llama-8B models: Llama-3.1 and AstroSage \citep{haan2025_astrosage}, where a Llama-3.1 model was fine-tuned specifically on arXiv astrophysics papers.~\Cref{tab:basemodel} shows the comparison on both datasets. While both models show high performance on both tasks, Astrosage retains a small gain over the vanilla model in seven of the eight cells, across both datasets, which implies that textual domain knowledge is helpful for those tasks. The margins are small and each arm was trained at a single seed, so the pattern across cells carries the claim rather than any one cell.  
\subsection{scientific reasoning tasks} Single and pair questions consists of description and simple comparisons and requires almost no reasoning beyond the basic properties. It is also similar to protein description tasks as in  \cite{Dotan2026_betadescribe}, and therefore it is not surprising that an LLM performs well on such questions. Next, we test the performance on questions that requires some form of scientific reasoning. As mentioned in~\Cref{sec:data}, those are anomaly detection for the stellar dataset and irregular morphology-SFH correlation in the galaxy dataset.~\Cref{tab:headboth} shows the results of those two tasks using both a template-based verifier and an LLM judge (Qwen3.5-27B). The \emph{no head} column presents the basic model, with no extra information, and the perforemance are poor. The \emph{+ head} column shows the performance with the addition of an extra single token that comes from a dedicated non-LLM model that is meant to highlight the relevant information. In the stellar case this is a flow matching model that was trained to learn the joint distribution of the aligned features and catalog labels, conditioned on the rest of the group. In the galaxy case, this is a cross-modal predictor that is trained to predict one modality from the other. We note that adding this single token significantly improves the performance on both tasks.

$^{\ast}$~The galaxies are scored by how well the model's graded confidence separates
true mismatches, taken as the minimum over the two star-formation strata ($0.50$ =
chance), rather than by whether the text states the right verdict. A verdict rate
saturates here: trained on the same prose, the narrator without the token calls $0.923$
of the mismatching galaxies correctly and the one with it $0.973$ --- both say the right
words. What separates them is that the narrator without the token learns
``spheroid $\Rightarrow$ mismatch'', which is right for the $90\%$ star-forming
majority and backwards for the quiescent minority.
