\section{Appendix}\label{sec:appendix}

\subsection{Is the signal in the features? The ranking probe}\label{app:probe}
The group task asks which member does not belong. We test whether that is
answerable from the aligned features alone, without a language model in the
loop. For each group we rank its members by one quantity and ask where a
qualifying star lands. Two readouts are compared on exactly the same groups:
the true catalog value, and a cross-fit ridge regression that predicts the same
quantity from the aligned feature (5-fold, so no star is scored by a model that
saw it). If the probe tracks the catalog, the signal survives the alignment.

The test groups are those of \Cref{tab:group}. Two details matter. First, only the three continuous axes can be ranked by a
scalar; binarity and cluster membership are categorical and are excluded, as are odd stars with a missing value
($689$ of $2{,}097$ odd stars). Second, the composer designates one intruder but
leaves the other members unconstrained on that axis, so a group often contains
several stars carrying the same label. Naming any of them is a true statement about
the group, so a readout is credited for the best-placed qualifying star rather
than only the designated one. ``Extreme'' is distance from the group median in
units of its median absolute deviation, which does not reveal which direction
the answer lies in.

The probe matches the catalog at rank-1 and keeps $97\%$ of it at top-3. The information for
this task is therefore in the features. On the $1{,}000$ never-odd groups ($525$ odd stars) the
result is the same: $0.733$ for the probe against $0.745$ for the catalog values.

The catalog row is not a ceiling on the task. It bounds what a \emph{single ranked quantity}
can do, and it falls short of $1.0$ because the label is a threshold test
(``$[\mathrm{Fe/H}] > 0.3$'') while a ranking is a distance test: a star can sit far from the
group median without crossing the threshold. This is largest for metallicity, where the
narrators, which state labels rather than distances, score above the probe. The narrators are
furthest below the probe on dwarfs and giants, which they classify well one star at a time
(\Cref{tab:single}).

Scoring the narrators by the judge while crediting any equally-qualifying star raises every
narrator ($0.332 \to 0.419$ for the fully fine-tuned narrator, $0.633 \to 0.717$ for the LoRA
narrator, and $0.662 \to 0.756$ for the tool narrator) and leaves the order unchanged
($n{=}1{,}203$ groups).

\textbf{LoRA instead of full fine-tuning.} With the same optimizer schedule, LoRA raises the
score from $0.33$ to $0.51$ on the test groups ($p<10^{-24}$) and from $0.28$ to $0.59$ on
the groups whose odd star was never odd in training ($p<10^{-60}$). This run had not
converged when it was stopped. It finds the odd star more often but makes more contradictions
than the fully fine-tuned narrator ($2.32$ against $1.90$ per group), so what LoRA brings at
this schedule is the identification of the odd star, not a more accurate description overall.

\textbf{The optimizer schedule and training length.} Moving to the schedule of the tool
narrator adds $0.12$ on the test groups ($p<10^{-12}$), only $0.03$ on the never-odd groups
($p=0.14$, not significant), and removes about two thirds of a contradiction per group on
both sets ($p<10^{-37}$). Since the previous run had not converged, we attribute this step to
the schedule and the training length together. Neither recipe was tuned, so a better recipe
for full fine-tuning may exist; LoRA is better without one.

\subsection{The catalog as text}\label{app:text}
Each text reader is tested twice: answering directly, and reasoning step by step before
answering. \Cref{tab:text} gives the full comparison.
No model that reads the numbers reaches the LoRA narrators ($0.633$ without the tool and
$0.662$ with it; $p<10^{-14}$ for the best text reader against the LoRA narrator without the
tool). AstroSage reading the table reaches the best score among them ($0.473$),
but by naming most of the group ($82\%$ of the stars): naming the odd star among
them is then no better than chance ($0.92\times$). Asked to reason first, it
names few stars and scores $0.288$, below the fully fine-tuned narrator. The
larger model is more selective: it names the odd star at about the same rate as
the tool relative to the number of stars it names. However, it often gets the
odd star's property wrong, and scores $0.341$ answering directly and $0.324$
after reasoning, no different from the fully fine-tuned narrator ($p{=}0.7$ in
both cases). In most groups ($94\%$) the larger model was still reasoning when
it reached the length limit of $4{,}096$ tokens and was made to answer from what
it had, so its reasoning result holds for this budget only. The gap to the LoRA narrators
also holds for every group size (\Cref{app:textsize}). Reading the numbers
lets a model describe the stars, but not reliably pick out the one that does
not belong.

\subsection{The templater}\label{app:templater}
Each description samples, independently, which facts to state (a random three to
six), a style and a framing.
\begin{itemize}
\item \textbf{Stars.} Three styles (natural prose, observation log, bullet list)
  and four framings (plain description, outlier flag, comparison with other
  stars, comparison with the Sun). With probability one half each, the
  templater adds a chemistry block (disk population, $\alpha$-abundance) and an
  activity block (chromospheric activity, variability amplitude). Each fact is
  then worded by drawing from a bank of alternative phrasings ($917$
  alternatives at $141$ points in the text). A star is described about five
  times, each time with different facts and words.
\item \textbf{Galaxies.} Four styles (technical paper, observation log, teaching
  text, concise summary), four framings (plain description, comparison with the
  galaxy population, comparison with the star-forming main sequence, outlier
  flag) and three lengths. There is one wording per fact and style, so the
  variety comes from the facts, style, framing and length.

  \emph{Star-formation history.} Each galaxy's SFH is the catalog's $50$-bin
  star-formation history, normalized to unit total mass. For a window covering
  the last $X\%$ of the Hubble time ($X = 5, 10, 20, 30, 50$), we compute two
  statistics: the trend index $i_X$, the difference between the mass formed in
  the recent and the earlier half of the window, divided by the mass formed in
  the whole window (positive for a rising SFH); and the recent mass fraction
  $f_X$, the fraction of the total stellar mass formed within the window. The SFH
  trend class is the sign of $i_X$ and a catalog-quantile bin of its magnitude.
  Each description states these quantities for one or two randomly chosen
  windows and names the window.
\end{itemize}
\textbf{Diversity.} Every stellar single and pair description is unique, and
$99.9\%$ remain unique with all numbers masked. For galaxies, $99.9\%$ of single
descriptions are unique and $70\%$ remain so with numbers masked.

\textbf{Corpora.} The stellar corpus has $1.93$M records ($1.01$M single,
$0.69$M pair, $0.23$M population); each population record is a group of $4$ to
$32$ stars with an odd member on one of six properties. The galaxy corpus has
$288$k records ($90$k single, $198$k pair). The galaxy agreement task uses a
separate, deliberately narrow corpus of $45{,}817$ records (three phrasings per
case, also from training galaxies only) in which galaxies whose morphology and
star-formation history disagree are oversampled to $33\%$.

\subsection{Templates against LLM-written prose}\label{app:corpus}
Everything above is trained on prose written by the deterministic templater.
The obvious alternative is to let a capable LLM write it, which has the potential for better diversity and fluency. To compare the two, we built an LLM-based corpus: the writer (DeepSeek-V4) was given the same
catalog facts and asked to write the group descriptions, and every claim it made
was checked against the record before the text was accepted. The training text
is, in that sense, true. \Cref{tab:corpus} compares the two corpora with
everything else held fixed: same base model, same prompt, and no tool (both narrators read the data tokens only and are fully fine-tuned). We see that training on the writer's fluent prose makes the narrator invent:
contradictions per group go from $1.9$ to $7.2$, and not one group out of
$1{,}191$ is described fully correctly (odd star and property named, typical members described correctly, and no statement contradicting the record). The training text was verified true; the
model trained on it is not. This is aligned with the finding of \cite{Hegselmann2022TabLLMFC} who showed that template-based serialization outperforms LLM-based serialization for tabular data. The two corpora differ in how much they commit to. Per group description, the
templater writes a median of $21$ words containing $5$ numbers and names $17\%$
of the members; it states the population and the member that does not belong,
and says nothing about the rest. The writer uses $82$ words containing $17$
numbers and names $83\%$ of the members, giving most of them a full quantitative
profile. Training on the second teaches the narrator to do the same. On the test groups,
the narrator trained on writer prose writes a median of $78$ words against $17$, states
$8$ values per group against $1$, and names $72\%$ of the members against
$26\%$. Most of its extra contradictions ($70\%$) are such numeric claims, and
most of those concern members \emph{other} than the outlier, whose values the
template-trained narrator rarely states at all. Per stated value, the two narrators are
contradicted at a similar rate ($0.52$ vs.\ $0.46$): the writer-trained narrator is
wrong more often mainly because it says more. Values for the typical members are hard to read
for both narrators: for either one about $40\%$ of them contradict the record
(verifier). A narrator trained to state them for every member therefore
mostly adds errors. This is not the whole story: on the outlier itself, the writer-trained
narrator's stated values contradict the record far more often ($18\%$ vs.\ $2\%$ of
values, verifier). Verification of the training text does not help in either
case, because the problem is not that the text is false; it is that it asserts
more than the input determines.

\subsection{The galaxy narrators: token or training?}\label{app:2x2}
The galaxy tool narrator differs from the fully fine-tuned narrator in two ways:
it reads the tool token, and it is trained with LoRA on a frozen base. To separate
the two, we trained a third narrator on the \emph{same} text with the \emph{same}
LoRA settings and no tool token, and we also ran the tool narrator with its token
scrambled at test time (each galaxy receives the tool token of another test
galaxy). All four narrators describe the same $10{,}677$ test galaxies, decoded
greedily, and are scored as in \Cref{sec:galaxyscore}.

Three things follow. First, the LoRA narrator without the tool token is as good
as the one with it: indistinguishable on quiescent galaxies and slightly better
on star-forming ones. Second, the fully fine-tuned narrator is clearly worse on
quiescent galaxies; most of its errors there come from stating that a quiescent
galaxy still forms stars. Third, scrambling the tool narrator's token costs it a

the improvement over the fully fine-tuned narrator therefore comes from the
training, not from the tool token. The stellar equivalent is in \Cref{sec:tokenortraining}.

\subsection{Data augmentation}\label{app:recipe}
\Cref{tab:recipe} tests the two parts of the data augmentation (\Cref{sec:data}) on the galaxy
data with Llama-3.1-8B. \emph{Novel phrasing} is the fraction of generated
descriptions that do not copy a training description (\Cref{app:eval}); low
values mean the narrator recites the templates.

The upper block adds the components one at a time on a $95$k-record subset,
with everything else fixed. Varying the input format raises accuracy on single
objects, but the narrator starts reciting its training text: novel phrasing

\subsection{Evaluation}\label{app:eval}
\textbf{Rule-based verifier (single and pair records).} A deterministic program
extracts every numeric and categorical claim from the generated text and checks
it against the object's catalog record. No model is involved. It reads values
written in running text (``a temperature of $5800$\,K'') and in list form
(``Surface gravity: $4.3$''). A negated statement counts as a claim of the
opposite (``not Sun-like'' is correct for a star that is not Sun-like), and a
galaxy's star-formation trend is checked over the time window the text names
(e.g.\ ``declining over the last $5\%$'').
\begin{itemize}\itemsep1pt
\item \emph{Numeric accuracy}: the fraction of stated values within $10\%$ of
  the catalog value. For quantities given as logarithms ($\log g$, $[\mathrm{Fe/H}]$,
  $\log M_\star$, $\log \mathrm{sSFR}$) this means $10\%$ in the underlying
  quantity, i.e.\ within $\log_{10} 1.1 = 0.041$\,dex. The galaxy
  star-formation trend index is signed and is zero for a flat history, so a
  relative tolerance is undefined for it; it keeps an absolute tolerance of
  $0.05$. A value off by more than three times the tolerance counts as a
  \emph{contradiction}. \Cref{tab:tol} gives the accuracy and the mean absolute
  error of each quantity separately.
\item \emph{Qualitative accuracy} (single): the fraction of class words that
  match the catalog. For stars: evolutionary state (dwarf, subgiant, giant) and
  group-relative classes (metallicity rank in four classes, hot/cool, fast/slow
  rotator, young/old, luminous/faint, Sun-like, metal-poor on an absolute scale). For galaxies: morphology class (early/late disk,
  elliptical, mixed), star-formation state (quiescent, green valley,
  star-forming, starburst) and mass class.
\item \emph{Relational accuracy} (pair): the fraction of comparisons that match the
  catalog. For stars: directional comparatives (hotter, more massive, larger,
  older, higher $\log g$, more luminous, more metal-rich, and their opposites).
  For galaxies: same or different morphology, star-formation-history trend,
  disturbance and density cluster.
\item \emph{Grounded} $=1-$ the fraction of claims not supported by the record.
\item \emph{Novel phrasing} measures whether the narrator writes its own
  sentences or recites training text. For each generated description we find
  the most similar description in the training corpus (MinHash nearest
  neighbour over word $5$-grams) and compute the fraction of the generation's
  $5$-word sequences that appear verbatim in it. A generation \emph{copies} a
  training description if at least half of its $5$-word sequences do. Novel
  phrasing is $1-$ the fraction of generations that copy.
\end{itemize}

\textbf{Scoring the galaxy task.}\label{sec:galaxyscore} We read three statements
from each galaxy description: the galaxy's shape (disk or spheroid), whether it
still forms stars, and the verdict, i.e., whether the description calls the two in
agreement. Each is read with a short list of words. For the verdict, ``mismatch'',
``disagree'', ``outlier'' or ``unusual'' mark disagreement, and ``concordant'',
``in accord'', ``concur'' or ``agree'' mark agreement. In the training text these
words are exact: every description containing a disagreement word belongs to a
disagreeing galaxy, and every one containing an agreement word to an agreeing
galaxy (\Cref{app:eval}). We report the fraction of galaxies with the correct
verdict, separately for star-forming and quiescent galaxies. The split matters
because $90\%$ of the test galaxies are star-forming, and the errors concentrate in
the quiescent minority, where a narrator must notice that a galaxy has stopped
forming stars. Whenever a narrator's verdict is right, its stated shape and
star-formation state are also right in more than $99.9\%$ of cases.

\textbf{The judge (stellar population records).} The verifier's extractors
expect the template's phrasing, so the population task is also scored by the
judge (Qwen3.5-27B), a text-only model that never sees any token. It reads each group
description against the ground-truth record and is instructed to judge factual
content only, not style. It returns: whether the text names the true odd member
(\emph{named}); whether it attributes it to the correct property
(\emph{property}); whether the population statement describes the typical
members (\emph{covered}); and a list of claims that contradict the record
(\emph{contradictions}). We derive \emph{score} = named \emph{and} property,
and \emph{all correct} = score, covered, and no contradiction. Only groups that
contain an odd member are scored. All narrators are judged on the same groups, so
comparisons are paired (exact McNemar for yes/no outcomes, Wilcoxon for
contradiction counts). The judge is given no numeric tolerance and is stricter
than the verifier: of the numeric contradictions it lists that we could parse, $56$--$60\%$ (depending on the narrator) are within
the verifier's tolerance. Its contradiction counts are therefore an upper bound,
and they inflate more for a narrator that states more numbers.

\textbf{Galaxy agreement task.} Each description is reduced to three statements,
read with fixed word lists taken from the nine single-galaxy templates of the
training text. \emph{Shape}: ``late-type disk'' or ``early-type disk'' (disk),
``elliptical'' or ``lenticular'' (spheroid); general phrases that state the rule,
such as ``spheroidal systems'', are ignored. \emph{Star formation}: the first of
``star-forming'' or ``still forming stars'' (star-forming) and ``quiescent'' or
``has quenched'' (quiescent); the galaxy's own state always precedes the rule
clause, as in ``This disk is quiescent --- \ldots{} disks usually remain
star-forming''. \emph{Verdict}: the words in \Cref{tab:verdictwords}; a
description containing words from both lists, or from neither, has no verdict.
\Cref{tab:verdictwords} checks every word against the ground truth of the
$36{,}654$ single-galaxy training descriptions; the shape and star-formation
rules are likewise correct on $100\%$ of them. A galaxy's verdict is scored
correct if it matches the catalog. No narrator left a galaxy without a verdict.

\subsection{Accuracy per property}\label{app:perprop}
\Cref{fig:perprop} breaks the single-object accuracy of AstroSage-8B down by
property, on the whole test set ($19{,}010$ stars, $3{,}000$ galaxies). Most
class statements are right more than $90\%$ of the time. The exceptions are
informative. For stars, the metallicity rank is right in $68\%$ of cases, and
most errors confuse two neighbouring classes (below and above the median);
subgiants are often called dwarfs ($59\%$ correct, against $98\%$ for dwarfs
and giants). Among stated numbers, temperature and mass are usually within
$10\%$, while radius, surface gravity, parallax and age often are not; age is
off by $1.5$\,Gyr on average. For galaxies, redshift and the mean
star-formation time are accurate, while stellar mass, specific star-formation
rate and the S\'ersic index are rarely within $10\%$ (stellar mass is off by

\subsection{Does the narrator say what the tokens contain?}\label{app:probevsnarrator}
\Cref{tab:single} compares the narrators with a linear probe and a non-linear probe: an MLP with
one hidden layer of $512$ units. Both probes are trained on the same inputs as the narrator (the
aligned star tokens; the image and star-formation-history embeddings of a galaxy) on the
training fold and evaluated on the test fold.

\paragraph{Stars.} On all test stars, the non-linear probe improves on the linear probe by at
most $0.02$ in $R^2$ and not at all on classes, so the star tokens encode these properties almost linearly.
The comparison with the narrators therefore does not depend on the probe. Part of the
narrators' advantage is recall. The narrator states the exact catalog temperature, to the
kelvin, in $35\%$ of its statements, against $0.5\%$ for the probe. Almost every such value
appears in a training description of the same star, which exists for $99.2\%$ of test stars
(\Cref{sec:data}). When the value appears in no training description, exact matches fall to
the probe's level. The effect on the mean error is small.

\paragraph{Galaxies.} No test galaxy appears in the training text. The non-linear probe
improves substantially on the linear one for galaxies (on all test galaxies, e.g.\
$\log M_\star$, $0.76 \to 0.85$; formation age, $0.88 \to 0.99$). On numerical properties the narrator is within $0.04$ of it,
and exceeds it for stellar mass. On classes the narrator matches it for morphology and is
below it for quenching state, SFH trend and disturbance ($0.03$--$0.13$). The
main gap is coverage rather than accuracy: the narrator states the stellar mass, specific
star-formation rate, redshift or S\'ersic index for only $2$--$18\%$ of galaxies, although
both probes recover them well.

\paragraph{Weak in both.} Some properties are hard for both probes, measured on all test objects:
stellar age ($R^2=0.55$), the metallicity quartile ($0.66$, against $0.25$ by chance) and the galaxy S\'ersic index. For
these properties the information is largely absent from the tokens, and the narrator's errors
(\Cref{fig:perprop}) reflect the tokens rather than the narrator.

\subsection{Training recipes of the stellar narrators}\label{app:recipes}
Full fine-tuning updates all weights of the language model, with a learning rate of
$5\times10^{-5}$, a cosine schedule with warm-up, and label smoothing of $0.05$. The LoRA
narrators freeze the base model and train low-rank adapters (rank $16$, $\alpha=32$) on the
attention query and value projections. The tool narrator and the LoRA narrator without the
tool use a constant learning rate of $2.83\times10^{-4}$ and no label smoothing. The LoRA
narrator with the full fine-tuning schedule uses the learning rate, schedule and label
smoothing of the fully fine-tuned narrator; it was stopped after $20$ epochs of a $50$-epoch
schedule, at which point its validation loss was still improving. No hyperparameters were
searched for any of these narrators.

\subsection{Frontier-model inputs}\label{app:frontier}
Each star is shown as fixed plots of its full Kepler light curve, a $20$-day segment of it,
one TESS sector, and its LAMOST and APOGEE spectra, together with its Gaia measurements as
text. No derived stellar parameter is shown. A group shows these panels for every member.

Plots may suit a vision model less than numbers do. We therefore replaced each plot with a
table of the same observations, binned to a few hundred values per curve or spectrum, and
reran Claude Opus 5.5 on a subset of the same items (\Cref{tab:frontierinput}). The results do
not change: the model states about the same fraction of numbers and classes correctly, and
it finds the odd star in about as few groups. The low score therefore does not come from the
plot format.

We also started a third version, in which the model can run code on the unbinned
observations. It ran on only three groups before we stopped it, which is too few to report.
