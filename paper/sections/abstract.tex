\begin{abstract}
Recent advances in Large Language Models (LLMs) offer unique opportunities for scientific tasks, yet their ability to reason over complex numerical data remains largely unexplored. While several works investigate the ability of LLMs to create textual descriptions of scientific objects (e.g., proteins), we ask whether they can understand those objects and answer comparative questions about them. This kind of reasoning beyond description is crucial for the development of useful co-scientists. We test two different astrophysical datasets, involving both stars and galaxies, with pre-trained multimodal features that serve as the LLM data tokens. Adding those tokens as additional information, we fine-tune an 8B Llama model on various scientific description and reasoning tasks. \dl{We find that the model can describe the stellar objects and compare pairs reasonably well in both datasets. On reasoning tasks, we find a sharp asymmetry: while the model can find cross-modal anomalies on galaxies, it fails when asked to identify outliers within a population of stars. We show that this failure is related to the fact that the model was asked about a set of objects and that the performance drops with the size of the set. We further show that delegating part of the group computation to a small model that is not a language model (a flow-matching model, for outlier-in-population questions) and returning its result to the LLM as latent tokens rather than as text dramatically improves the LLM's performance and eliminates the dependency on set size. We call this \emph{latent tool use (LTU)}. In addition, we show that for such questions, a template-based dataset is preferable to an LLM-based dataset. The results highlight the lack of statistical reasoning abilities in current language-based models and the need for dedicated models to transform the data in a way that helps LLMs understand it.  }\nw{We find that the model can describe the objects and compare pairs reasonably well in both datasets. On reasoning tasks, the outcome depends strongly on how the language model is adapted. Fully fine-tuned, the model can find cross-modal anomalies on galaxies, but it fails to identify outliers within a population of stars, and its performance drops with the size of the population. Training only a low-rank adapter (LoRA) on a frozen base model, with neither method's hyperparameters tuned, nearly doubles the stellar score, removes the dependence on population size, and improves the galaxy task; most of the gain remains when the two methods share one optimizer schedule. We further show that a small flow-matching model, which receives catalog labels as auxiliary data and returns its output to the LLM as latent tokens rather than as text, improves the identification of outliers that were never outliers in training ($0.62 \to 0.75$). We call this \emph{latent tool use (LTU)}. Frontier general-purpose models given the raw observations zero-shot, without tools, score well below these narrators. In addition, we show that for such questions, a template-based dataset is preferable to an LLM-based dataset. The results indicate that a language model reading learned scientific features can perform population-level reasoning when it is adapted with a low-rank adapter, and that a dedicated model given auxiliary labels adds to this where the training data offers no precedent.  }
\end{abstract}
