\begin{abstract}
Recent advances in Large Language Models (LLMs) offer unique opportunities for scientific tasks, yet their ability to reason over complex numerical data remains largely unexplored. While several works investigate the ability of LLMs to create textual descriptions of scientific objects (e.g., proteins), we ask whether they can understand those objects and answer comparative questions about them. This kind of reasoning beyond description is crucial for the development of useful co-scientists. We test two different astrophysical datasets, involving both stars and galaxies, with pre-trained multimodal features that serve as the LLM data tokens. Adding those tokens as additional information, we fine-tune an 8B Llama model on various scientific description and reasoning tasks. We find that the model can describe the stellar objects and compare pairs reasonably well in both datasets. On reasoning tasks, we find a sharp asymmetry: while the model can find cross-modal anomalies on galaxies, it fails when asked to identify outliers within a population of stars. We show that this failure is related to the fact that the model was asked about a set of objects and that the performance drops with the size of the set. We further show that training a small, non-language head to highlight scientific information (e.g., a flow-matching model for outlier-in-population questions) and adding its latent features as an extra token dramatically improves the LLM's performance and eliminates the dependency on set size. We call this approach \emph{latent tool use (LTU)}. In addition, we show that for such questions, a template-based dataset is preferable to an LLM-based dataset. The results highlight the lack of statistical reasoning abilities in current language-based models and the need for dedicated models to transform the data in a way that helps LLMs understand it.  
\end{abstract}
