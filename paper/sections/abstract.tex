\begin{abstract}
Large Language Models (LLMs) can describe scientific objects, but can they analyse data
directly from a learned scientific representation? We connect pre-trained multimodal encoders
of stars and of galaxies to an 8B language model and ask whether their features are a
sufficient interface for analysis beyond description. Two reference points bracket the
results: linear probes on the same features show what the representation contains, and
frontier models given the raw observations show what is reachable without it. The language
model describes single objects about as well as the probes, on both datasets. Finding the odd
member of a group of stars depends on how the model is adapted. Fully fine-tuned, it fails in
two thirds of groups, and fails more often as the group grows. Trained with a low-rank adapter
(LoRA) on a frozen base, on the same data, it succeeds in about two thirds of groups at every
group size, including groups whose answer never appeared in training; galaxies show the same
effect of adaptation. A probe confirms that the features contain the answer. Models that read
the catalog values as text without training on the task, and frontier models given the raw
observations zero-shot, score below the LoRA model. As a preliminary extension, a small model
that passes auxiliary catalog labels to the language model as latent tokens helps on groups
unlike those seen in training. Comparisons with a text-trained model and with frontier agents
that run code are in progress.
\end{abstract}
